# 🌐 Pooja's Portfolio

A modern and responsive personal portfolio website built using HTML, CSS and JavaScript.

## ✨ Features

- Responsive Design
- Modern Glassmorphism UI
- Smooth Scroll Animations
- Interactive Project Showcase
- Skills Section
- Certificates Section
- Contact Information
- Resume Download
- Mobile Friendly

- HTML5
- CSS3
- JavaScript
